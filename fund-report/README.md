# 基金配置建議書產生器

比較表列基金，配置後輸出兩種 A4 PDF：**基金比較表**與**客戶建議書**（含配息與本金成長預估）。

不需要安裝任何東西，也不需要網路。用瀏覽器打開就能用。

---

## 一、怎麼打開

| 方式 | 做法 | 適合 |
|---|---|---|
| 最簡單 | 下載 `standalone.html`，用 Chrome 或 Edge 打開 | 自己用、傳給同事 |
| 完整版 | 下載整個 `fund-report` 資料夾，打開 `index.html` | 要改資料或改版面 |
| 放上網 | 見文末「放到 GitHub Pages」 | 團隊共用一個網址 |

> 建議用 **Chrome 或 Edge**。輸出 PDF 的版面是以這兩個瀏覽器的列印引擎校正的。

---

## 二、四個分頁

### 1. 基金比較
35 檔基金與 ETF 的淨值、風險等級（RR）、投資方向、前五大持股。

- 上方色塊按分類篩選，也可以用關鍵字搜尋**基金名稱、投資方向或持股**（例如打「台積電」會列出所有持有台積電的標的）
- 點欄位標題可排序
- 報酬率後面有 `*` 表示該基金成立時間不夠長，該年期沿用了較短年期的數字
- **輸出比較表 PDF** — 依分類分頁，每頁最多 8 檔
- 每列右側的**加入配置**把標的送進下一頁

### 2. 配置試算
- 直接改比例數字，右側金額與月配息即時重算
- 比例不用湊到 100%，系統會按相對比重換算；要湊整的話按**調整為 100%**
- 左上填客戶姓名、承辦顧問、方案名稱與投資金額，這些會印在建議書抬頭

**配息處理方式**（這一項會明顯改變預估數字，請依客戶實際情況選）：

- **配息再投入（總報酬）** — 配息滾回本金。與一般平台的績效表達方式一致，數字最好看。
- **配息領出** — 客戶每月實領現金。本金只以「總報酬扣掉配息率」成長，累計已領配息另外計算。**客戶如果真的按月把錢花掉，要選這個**，否則會高估未來本金。

### 3. 建議書
螢幕上看到的就是印出來的樣子。內容對應原本的六個段落：投資計畫總覽、預估成效分析、配置明細表、動能成長分析、資產配置區域分析、持倉明細附錄。

標的多的時候整頁會自動等比縮小，確保剛好一頁、不會多印一張空白紙。

### 4. 資料維護
所有修改只存在**這台電腦的瀏覽器裡**，不會上傳到任何地方。換電腦或換瀏覽器要用「匯出備份 JSON／匯入備份 JSON」搬移。

---

## 三、輸出 PDF

按**輸出建議書 PDF** 或**輸出比較表 PDF**，列印視窗會跳出來，然後：

1. 目的地／印表機 → **另存為 PDF**
2. 版面配置 → **直向**
3. 更多設定 → 邊界 → **無**
4. 更多設定 → **勾選「背景圖形」**（沒勾的話顏色和底色會不見）

紙張大小維持 A4 即可。

---

## 四、資料哪些是真的、哪些是假設 ⚠️

這是使用前**一定要理解**的一件事。

| 欄位 | 性質 | 來源 |
|---|---|---|
| 淨值、淨值日 | 公告事實 | 2026/08/10 版比較表 |
| RR 風險等級 | 公告事實 | 同上（不同通路可能略有差異）|
| 投資方向、前五大持股、持股日 | 公告事實 | 最近一期公開月報／ETF 每日持倉 |
| **年化配息率** | **假設值** | 內建預設，**必須自行核對** |
| **各年期年化報酬率** | **假設值** | 內建預設，**必須自行核對** |

**年化配息率**決定建議書上的「預估月領息」，**各年期年化報酬率**決定「5 年／10 年資產預估」。這兩欄是內建的合理預設值，不是官方公告數字。

**提供給客戶之前，請到「資料維護」分頁依最新月報或平台資料覆寫這兩欄。**

介面上凡是有虛線底線的數字（例如年化配息率）都是假設值，滑鼠移上去會提示。

## 五、更新資料的兩種方式

### 快速：貼上更新
從 Excel 或平台複製後直接貼進「批次更新」的方框，一行一檔：

```
安聯收益成長 AMg7	8.8629	2026/08/11	9.5
0050	102.85	2026/08/11	2.8
QQQ	723.03	2026/08/11
```

欄位順序是 **名稱、淨值、淨值日、年化配息率**，用 Tab 或逗號分隔，後面兩欄可以省略。名稱只要包含得到就會對上（打「0050」就找得到「0050 元大台灣50」）。找不到的會在下方提示，不會靜悄悄跳過。

### 逐筆：直接編輯表格
下方表格可以逐欄改淨值、淨值日、RR、配息率與各年期報酬率。改完自動存檔。

## 六、要加新基金

打開 `assets/funds.js`，複製一整段 `{ ... }` 改內容即可，欄位說明都寫在檔案最上面。改完如果有用 `standalone.html`，要重新產生一次：

```bash
python3 build-standalone.py
```

---

## 七、放到 GitHub Pages（團隊共用網址）

1. 在這個 repo 的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，分支選 `main`，資料夾選 `/ (root)`
3. 存檔後等一兩分鐘，網址是
   `https://<你的帳號>.github.io/<repo 名稱>/fund-report/`

## 八、技術說明

- 純 HTML + CSS + JavaScript，**沒有任何外部套件或 CDN**，離線可用
- 圖表是自己畫的 SVG，列印時不會糊掉
- 圖表配色通過色盲辨識度檢驗，深淺色模式各自校正過
- 建議書的紙張樣式固定為淺色，切到深色介面也不會印出深色底

### 檔案結構

```
fund-report/
├── index.html              介面骨架
├── standalone.html         打包後的單一檔案（可單獨傳送）
├── build-standalone.py     產生 standalone.html
└── assets/
    ├── funds.js            基金資料庫 ← 要改資料看這裡
    ├── app.css             介面樣式與色彩
    ├── print.css           A4 文件樣式
    ├── charts.js           SVG 圖表引擎
    └── app.js              計算模型與畫面邏輯
```

### 預估模型

各年期**分別**採用該年期的年化報酬率推算，而不是套用單一固定報酬率：

```
第 N 年資產 = 投入本金 × (1 + 該投資組合第 N 年年化報酬率)^N
```

投資組合的第 N 年年化報酬率＝各標的該年期年化報酬率，依配置比例加權。

選「配息領出」時，本金部位改以（總報酬率 − 年化配息率）成長，累計已領配息另外累加。

---

本工具僅供理財規劃參考，所有預估數字非保證收益，也不代表未來實際報酬。實際投資決策請洽專業人員並詳閱公開說明書。
